# 封面设计助手 · dsh-cover-studio

一个安装在 **DeepSeekHarness (DSH)** 里的本地视频封面工作台：用中转站生图模型生成无字背景，本地用思源宋体/黑体排版标题，再在画布里改字、加图层、抠图、换人物，最后导出 PNG / JPG。

仓库地址：<https://github.com/2307918080lmx-lang/dsh-cover-studio>

项目不另训模型，所有风格、参考图和项目数据都保存在本机 DSH 数据目录；中转站 Key 只保存在本机，不会写进仓库，也不会通过设置接口回显。

## 功能

- **1–6 张不同版式**：16:9、9:16、4:3、3:4、1:1、3:2、5:4、2.35:1、21:9 和自定义 W:H。
- **单张封面精确复刻**：对分区库里的任意一张参考封面点「复刻这张」，视觉模型会单独拆解构图、标题位置、字体、颜色、行数、字距和画面气质，生成专用复刻卡；生成时字体/文字位置/颜色作为硬约束，并会把参考封面作为第二张图片辅助版式。
- **参考封面 AI 模板**：参考图库「拆成模板」会用视觉模型识别文字和版式，让中转站生成干净无字背景，再把文字变成可编辑图层；编辑器里可以「AI 重绘 / 换人物」，修改反推提示词、选择人物参考图重新生成同风格画面。
- **保持内容改比例**：后台任务把原封面扩展/重绘到新比例，可选 AI 扩图或本地快速扩展；原图始终保留，完成后并排展示原图和新图。
- **手动画布**：底图裁切/缩放、横竖排文字、导入字体、图片/贴纸、AI 找素材、形状/箭头/批注、亮度/对比度/饱和度/模糊、图层面板、快速标题组、标题安全区。
- **抠图**：AI 框选 + Silueta 本地分割、对象级去边、画笔抠图（红色=将去除，涂抹=保留），工具条可停靠、浮动、收起。
- **分区风格库**：动画/生活/科技/知识/游戏等分区，抓取 B 站高播放封面，支持指定 UP 主、全局去重、随机翻页、分区学习、加入参考图库和批量操作。
- **灵感板**：AI 给出 4 个真正不同的构图方向与免费草图。
- **文档参考**：读取 TXT / MD / PDF / DOCX，把文档内容和参考图一起用于创作。
- **主题与窗口**：多套主题、自定义强调色/明暗/圆角；窗口标题栏拖动、四边四角缩放、最大化、可拖动的最小化胶囊。
- **问题反馈**：工作室左侧「问题反馈」直接打开制作人的飞书问题反馈表单（支持上传截图）；链接只在源码常量里，设置界面不提供修改入口。

## 环境要求

- DeepSeekHarness（建议 0.2.x 或更高）
- Node.js 20+
- Windows / macOS / Linux；本地字体、裁剪和抠图使用 `@napi-rs/canvas` 与 `onnxruntime-node`
- 一个 OpenAI Images 兼容的生图中转站（OpenAI 官方、硅基流动、302.AI 或其他兼容服务）
- 可选：标题宋体/黑体字体文件。未配置时使用系统安装的中文字体。

## 安装到 DSH

1. 克隆或下载本仓库到本机，例如 `D:/plugins/dsh-cover-studio`。
2. 在 DSH 的 desktop profile（通常是 `$DSH_HOME/profiles/desktop/package.json`）的 `dependencies` 里加：

   ```json
   "dsh-cover-studio": "link:D:/plugins/dsh-cover-studio"
   ```

   macOS / Linux 使用 `file:/Users/you/plugins/dsh-cover-studio` 或你的包管理器支持的写法。
3. 在同一个 `package.json` 的 `dsh.profile.bundles` 末尾加 `"dsh-cover-studio"`。
4. 在插件目录安装依赖：

   ```bash
   cd D:/plugins/dsh-cover-studio
   npm install
   npm run fetch-model   # 可选：下载本地抠图模型（约 43MB）
   ```

   `npm run fetch-model` 会从 rembg 官方 release 下载 Silueta 并校验 SHA-256。不下载也能使用，抠图会自动回退到本地边缘算法。
5. 重启 DSH（或重载插件）。输入框上方/页面右下角会出现「封面」按钮，点击打开可拖动的工作室窗口；对话中提到封面/缩略图/B 站封面时也会触发 Agent 工具。

> 如果只想预览 UI，不安装 DSH：

```bash
npm install
npm run dev
# 打开 http://127.0.0.1:8790/
```

独立预览默认使用 `~/.dsh-cover-studio-dev` 数据目录。

## 第一次使用

1. 打开「封面」→ 设置 → 中转站 API。
2. 可以直接点 **OpenAI 官方 / 硅基流动 / 302.AI** 预设，自动填入接口地址、模型和尺寸；也可以添加任意多个自定义中转站。
3. 填入自己的 API Key，点「测试连接」。
4. 主模型默认跟随 DSH 的 DeepSeekFlash；若需要，可以在设置里切到自定义 API。
5. 回到「开始创作」：写主题、标题、副标题，选择风格、张数和画幅，生成。
6. 生成结果可以「编辑」改字/图层，「保持内容改比例」换画幅，「导出」保存 PNG+JPG。

## 参考封面与模板

- **复刻某一张封面**：风格库 → 分区风格库 → 展开分区 → 封面卡片「复刻这张」。每张封面单独生成一张复刻卡，不会混合整个分区。
- **把一张封面拆成可编辑模板**：参考图库 → 卡片「拆成模板」。AI 识别文字和版式并生成无字背景；进入编辑器后可以改字、移动图层。
- **AI 重绘 / 换人物**：模板编辑器顶部「AI 重绘 / 换人物」。反推提示词已预填，可修改；可填写新人物描述，或选择/上传人物参考图。文字图层保留，新版本独立保存，不会覆盖原模板。
- **旧版复刻卡**：第一次用于生成时会自动补做一次视觉拆解，补齐字体/标题框/版式；也可以手动点「重新拆解」。

## 常见问题

**生成失败 / 没有 API Key**  
设置 → 中转站 API 填写 Base URL、Key、模型并测试连接。Base URL 通常填到 `/v1`。

**中转站不支持 `images/edits` / 多图**  
插件会自动从多图参考退回单图；如果中转站完全不支持图片编辑，模板的 AI 清字会明确报错，而不是生成一张马赛克假模板。换一个支持 OpenAI Images edits 的中转站即可。

**抠图很慢或不可用**  
运行 `npm run fetch-model` 下载 Silueta；首次加载约 1–2 秒。没有模型时会退回本地边缘算法。

**字体不对**  
在设置里指定中文宋体/无衬线字体文件；本地排版优先使用思源宋体 Heavy / 系统字体。参考封面里的字体气质只用于提示词和复刻参数，不会直接复制字体文件。

**反馈问题**  
工作室左侧「问题反馈」直接打开飞书表单；请填写操作步骤、实际现象并上传截图。
